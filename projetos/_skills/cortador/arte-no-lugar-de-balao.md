# Escolha quadro de arte, nunca de texto
Para cada fala escolha o quadro cuja descrição tem personagem, ação ou cenário. Quadro descrito como balão, caixa de texto, placa, logo, título ou onomatopeia nunca é escolhido, mesmo quando o texto dele é igual à fala. Página sem arte que sirva: não crie recorte; a fala fica no recorte vizinho.

# Não repetir o mesmo recorte perto
Não use o mesmo quadro nem um recorte quase igual dentro de 6 partes, a não ser pela regra de segurar a imagem. Quando o capítulo tem poucas imagens, varie com outro trecho do mesmo quadro (mais largo ou mais próximo, dentro dos limites de tamanho). Repetir um recorte que o usuário já ajustou à mão é o erro mais notado: evite.
